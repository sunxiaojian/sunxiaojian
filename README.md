## About me

My main focus is data infrastructure: contributing to open-source data projects and building Java-based connectors that move data between messaging systems, data lakes, and query engines. Alongside that, I work on AI agents and the harnesses that run them.

- **Upstream contributions:** catalog, connector, and lakehouse features in Apache projects.
- **Streaming integrations:** connecting Kafka Connect with data platforms.
- **Lakehouse workflows:** bringing streaming data into Apache Paimon.
- **SQL over messaging data:** querying Apache RocketMQ through Trino.
- **Agent engineering:** building AI agents and the harness layer around their execution.
