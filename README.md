## About me

I build Java-based connectors that bring messaging systems, data lakes, and query engines closer together. My public projects explore how data moves between systems—and how to make that data easier to query.

- **Streaming integrations:** connecting Kafka Connect with data platforms.
- **Lakehouse workflows:** bringing streaming data into Apache Paimon.
- **SQL over messaging data:** querying Apache RocketMQ through Trino.
