## About me

I work on AI agents and the harnesses that run them, alongside Java-based data infrastructure that connects messaging systems, data lakes, and query engines. Both sides share the same question: how do you move information reliably between systems, and make it usable once it arrives?

- **Agent engineering:** building AI agents and the harness layer around their execution.
- **Streaming integrations:** connecting Kafka Connect with data platforms.
- **Lakehouse workflows:** bringing streaming data into Apache Paimon.
- **SQL over messaging data:** querying Apache RocketMQ through Trino.
